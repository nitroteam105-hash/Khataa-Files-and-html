Mobile Command Implementation Skeleton v2

This pass fills in the next major set of PG commands behind the mobile service boundary.

New concrete handlers: Add upcoming tenant, deterministic monthly obligations, payment reversal, add charge, add expense, cash handover/discrepancy, plan move-out, end tenancy and security refund.
Still proposed engineering: exact repository library, SQL driver and background-job framework remain open. The handlers are written against small interfaces so the domain rules do not depend on the mobile framework.

Monthly obligation generation

active / planned-move-out tenancy ↓ effective rent term ↓ for each monthly calendar period ↓ deterministic key: rent:<tenancyId>:<periodStart> ↓ already exists? ├─ yes → skip └─ no → create obligation + event + outbox running the generator twice produces no duplicate rent obligation

End tenancy behavior

End tenancy ↓ end active occupancy assignment ↓ set tenancy → moved_out ↓ append tenancy_ended event ↓ queue sync ↓ DO NOT delete: obligations payments receipts security pending refund statement history

Cash handover behavior

expected cash vs actual cash ↓ record explicit handover ↓ difference? ├─ no → done └─ yes → append discrepancy event No tenant payment row is changed.
