Local Sync Metadata Correction v1.1

This removes the remaining contradiction between immutable business history and mutable synchronization bookkeeping.

New in this file: ACK state, server versions, retry errors and conflict status are centralized in sync_entity_state. Immutable domain rows no longer need sync bookkeeping updates.
Compatibility migration: legacy sync columns are backfilled into the new state table first. A later physical table rebuild may remove the old columns; application code should stop using them immediately.

Command-side correction

The v2.1 patch replaces sync_status='pending' writes on domain records with a single helper that writes the outbox row and sync_entity_state atomically. Mutable domain records may still be updated for real business reasons, but not merely for transport bookkeeping.

Additional hardening

Payment allocations and financial adjustments are explicitly append-only. The patch also records the remaining billing-generator constraint: choose one effective rent term per period, respect actual tenancy start/end eligibility, preserve the deterministic monthly key, and do not invent proration without a product decision.
