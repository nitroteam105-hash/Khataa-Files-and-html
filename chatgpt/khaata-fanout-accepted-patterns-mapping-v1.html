FANOUT accepted patterns

15 accepted reference patterns mapped to possible Khaata uses. This file does not change the Khaata design-system source of truth.

New in this file: the accepted FANOUT review is translated into Khaata-relevant opportunities and guardrails. Nothing here is standardized yet; adoption still happens only when a real Khaata screen needs the pattern.

Cards & layouts

Fanout reference

Large editorial destination cards with distinct color blocks.

Possible Khaata use

Use only for non-status destination hubs such as More, Setup or configuration areas.

Guardrail: Do not use status colors decoratively on operational screens.
Fanout reference

Mostly neutral card with a soft favorable green treatment concentrated at the top.

Possible Khaata use

Candidate for plan choice, backup/sync choice, or another screen with one recommended option.

Guardrail: Recommendation treatment must not be confused with Done/complete.
Fanout reference

Eyebrow → dominant value → support line → explanation → lower action row.

Possible Khaata use

Useful for plans, limits, entitlement summaries, and value-based choices.

Guardrail: Keep Khaata action semantics for the CTA.
Fanout reference

Peer destinations presented as large side-by-side modules.

Possible Khaata use

Useful for More/Settings or setup hubs on wider mobile/tablet layouts.

Guardrail: Fall back to one column where width is insufficient.

Navigation

Fanout reference

White navigation panel over a dimmed page.

Possible Khaata use

Reference for secondary/global navigation on wider layouts or future web.

Guardrail: Does not replace Khaata bottom navigation on mobile.
Fanout reference

Parent navigation row expands inline to reveal child destinations.

Possible Khaata use

Useful in More/Settings when several related destinations sit under one heading.

Guardrail: Parent row should remain understandable even when collapsed.
Fanout reference

Compact brand/title area with small utilities.

Possible Khaata use

Useful on content-heavy or settings screens where vertical space matters.

Guardrail: Must coexist with Khaata mobile navigation conventions.

Emphasis

Fanout reference

Compact dark announcement strip with short copy and dismiss action.

Possible Khaata use

Candidate for rare informational announcements, not operational alerts.

Guardrail: Do not replace Khaata alert/caution/notice status components.
Fanout reference

Soft green gradient gives a positive/recommended feeling without filling the full card.

Possible Khaata use

Use as a recommendation/emphasis layer for favorable choices.

Guardrail: Needs its own recommendation token/treatment if standardized.
Fanout reference

Expanded/active parent row receives a quiet background highlight.

Possible Khaata use

Good for menus, accordions, and navigation groups.

Guardrail: Active state must still be explicit beyond color alone.

Actions

Fanout reference

Minimal menu control that opens a larger navigation surface.

Possible Khaata use

Useful where an overflow/secondary menu is needed.

Guardrail: Use a real button and Lucide icon in Khaata.

Visual language

Fanout reference

Bold orange, purple, lime, blue and yellow used to identify destination modules.

Possible Khaata use

Reference for non-semantic section identity or illustration-led hubs.

Guardrail: Never override Khaata semantic color meanings.
Fanout reference

Large, tightly tracked display headings create strong hierarchy.

Possible Khaata use

Could be used sparingly in onboarding, empty states, setup hubs, or plan pages.

Guardrail: Operational lists should stay compact and readable.
Fanout reference

Small neutral text sits quietly under strong titles and values.

Possible Khaata use

Directly compatible with Khaata’s secondary text hierarchy.

Guardrail: Maintain sufficient contrast in dark mode.
Fanout reference

Large radii soften cards, drawers and strong color blocks.

Possible Khaata use

Useful for destination cards, option cards and large surfaces.

Guardrail: Keep consistency with Khaata radius tokens rather than arbitrary radii.
