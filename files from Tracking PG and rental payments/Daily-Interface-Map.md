# Daily Interface Map — Primary Actions per Business

The home screen should surface only what an owner **touches often during a normal day** — not every feature. Everything else lives one level deeper.

This document works out, for each business, the 4–6 **primary tiles** that belong on the home screen.

---

## The Method

For each business, ask three questions:
1. **What happens many times a day?** → must be a tile
2. **What happens daily but few times?** → tile if room
3. **What happens weekly/monthly?** → NOT a tile, goes in nav

Then separate into:
- **Common spine** — actions almost every business does daily
- **Signature actions** — the 1–2 things unique to that business's daily rhythm

---

## THE COMMON SPINE (nearly every business)

These four recur across almost all 62 types:

| Action | Why it's daily | Frequency |
|---|---|---|
| **Collect / record payment** | Money comes in constantly | Many times/day |
| **Onboard new person** | New tenant/member/student/customer | Daily–weekly |
| **My staff** (attendance + salary) | Staff show up daily | Daily |
| **My bills** (money out) | Expenses logged as they happen | Daily |

Plus a near-universal fifth:
| **Pending / dues view** | "Who hasn't paid?" — checked constantly | Many times/day |

## SIGNATURE ACTIONS BY BUSINESS

The differentiator: what makes *this* business's day unique.

---

### RESIDENTIAL / STAY

**PG / Hostel**
Primary tiles: **Collect rent · Add tenant · Pending dues · My staff · My bills**
Signature: *Room/bed status* (who's in, what's vacant) — checked when someone enquires
- Daily rhythm: collecting rent, fielding "any room available?" enquiries, mess headcount
- Secondary (nav): mess management, complaints, deposits, agreements

**Hotel / Lodge / Service Apartment**
Primary tiles: **Check-in · Check-out · Rooms available · Collect payment · My staff**
Signature: *Check-in / Check-out* — the core daily verb; *Room availability* board
- Daily rhythm: guests arriving and leaving all day, housekeeping status, walk-in "room hai?"
- This is the most time-driven business — availability + check-in/out dominate the day
- Secondary: bookings calendar, housekeeping, bills

**Homestay / Dharamshala**
Primary tiles: **Check-in · Check-out · Rooms free · Collect/Donation · My staff**
- Same as hotel but lighter; donation receipts for dharamshala

**Old Age Home / Rehab**
Primary tiles: **Resident status · Medication/care log · Collect fee · My staff · My bills**
Signature: *Daily care/medication log* — happens multiple times daily per resident
- Daily rhythm: care rounds, medication, family calls — money is secondary to care tracking

### FITNESS & WELLNESS

**Gym / Fitness**
Primary tiles: **Member check-in · Collect fee · Add member · Renewals due · My staff**
Signature: *Renewals/expiry* (silent expiry = lost revenue) + *member check-in* (attendance)
- Daily rhythm: members walking in (check-in scan), new joiners, chasing expiring memberships
- Secondary: body metrics, trainer assignment, batch schedule, bills

**Yoga / Dance / Martial Arts (class-based)**
Primary tiles: **Mark attendance · Collect fee · Add student · Class schedule · My staff**
Signature: *Class attendance* (session-pack countdown) + *today's class roster*
- Daily rhythm: who's in today's batch, session-pack deduction, fee follow-up

**Swimming Pool / Sports Academy**
Primary tiles: **Batch attendance · Slot/court status · Collect fee · Add member · My staff**
Signature: *Slot/court availability* + batch attendance

**Spa / Salon / Physiotherapy**
Primary tiles: **Today's appointments · Check-in client · Collect payment · Add client · My staff**
Signature: *Appointment book* — the day runs on the appointment calendar
- Daily rhythm: appointments arriving, walk-ins, wallet/credit balance, therapist assignment

### EDUCATION & COACHING

**Coaching / Tuition Center**
Primary tiles: **Student attendance · Collect fee · Add student · Today's batches · My staff**
Signature: *Student attendance* (per batch) + *fee dues*
- Daily rhythm: marking attendance per batch, fee collection, parent queries
- Secondary: test scores, batch schedule, teacher assignment, bills

**Preschool / Daycare**
Primary tiles: **Child check-in/out · Daily activity log · Collect fee · Add child · My staff**
Signature: *Child check-in/out* (with authorized pickup) + *activity/photo updates to parents*
- Daily rhythm: drop-off/pickup, parent updates, meal/nap log — safety-critical
- Most parent-communication-heavy of all

**Driving School**
Primary tiles: **Today's slots · Mark session done · Collect fee · Add learner · My staff**
Signature: *Slot schedule* (vehicle + instructor) + session progress

**Library / Study Hall**
Primary tiles: **Seat check-in · Seat availability · Collect fee · Add member · My bills**
Signature: *Seat availability/booking*

**Home Bakery / Cake Shop**

## THE UNIVERSAL TEMPLATE

Distilling all of the above, every business's home screen =

```
┌─────────────────────────────────────┐
│  [Business switcher ▾]    🔔  👤      │
├─────────────────────────────────────┤
│  PRIMARY TILES (4–6, business-specific)│
│                                       │
│  [ Signature action 1 ]  ← the daily verb
│  [ Signature action 2 ]  ← (if any)   │
│  [ Collect payment ]     ← spine      │
│  [ Onboard person ]      ← spine      │
│  [ My staff ]            ← spine      │
│  [ My bills ]            ← spine      │
├─────────────────────────────────────┤
│  Money snapshot (in / out / net)      │
├─────────────────────────────────────┤
│  Needs attention (dues, expiring...)  │
├─────────────────────────────────────┤
│  Bottom nav: Home·People·Money·Reports·Settings │
└─────────────────────────────────────┘
```

**The rule:** signature action(s) on top (biggest), then the spine. Max 6 tiles. Everything rarer goes in the nav sections.

## DESIGN PRINCIPLES (so it stays quick, not cluttered)

1. **Max 6 primary tiles.** The power is focus. More tiles = slower, not faster.
2. **Signature action is biggest/first.** The thing they do 20×/day should be unmissable.
3. **The spine is consistent** across businesses → an owner running two businesses still recognizes "collect payment," "my staff," "my bills" in the same spot.
4. **Frequency decides placement**, not importance. Deposits matter, but happen rarely → nav, not tile. Check-in happens hourly → tile.
5. **One tap to the action, second tap to do it.** Tile → action screen → done. Never bury a daily action 3 levels deep.
6. **The signature tile is set at onboarding** (from the business type chosen) but **owner can customize** which tiles show — because every owner's habits differ slightly.

## CUSTOMIZABLE QUICK TILES (owner personalization)

Default tiles are a starting point, not a cage. Owners (even within the same business) work differently, so the home screen's quick actions must be **add / remove / reorder**-able.

### Two layers of customization
```
Layer 1 (automatic): business type → default tiles   [app decides, works out of the box]
Layer 2 (manual):     owner adds / removes / reorders  [owner decides, optional]
```
- Layer 1 → a non-tech owner never has to configure anything; defaults just work.
- Layer 2 → a power user tunes the screen to their exact daily workflow.

### How it works
1. **Smart default first** — on setup, app auto-picks tiles for the business type (from the map above). No forced configuration.
2. **Edit mode** — small ✎/⚙️ on the quick-actions section → add, remove, drag-reorder tiles.
3. **Tile library** — "+ Add tile" shows all available quick actions for that business (spine + signature + cross-context ones): Collect payment, Add person, Send reminders, My staff, Scan/check-in, Pending dues, Mark attendance, Today's headcount, Room/slot status, Record expense, Generate bill, etc. Tick to add.
4. **Guardrails:**
   - Cap at ~6–8 tiles (speed depends on focus; more tiles = slower).
   - Spine actions suggested but removable (gentle warning: "Most owners keep 'Collect payment'").
   - Instant, reversible; "Reset to default" available.

### Design rule
**Default-first, customize-optional.** Defaults must be good enough that ~70% never touch them; customization is discoverable but never demanded. Avoid overwhelming simple users with configuration on day one.

### Future (not MVP)
Usage-based suggestions — "You open 'Mess headcount' from the menu daily — add it to home?" Auto-personalization layered on top of the manual version once that's proven.
