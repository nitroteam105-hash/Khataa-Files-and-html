# Khaata — Business Category Map

**Baseline assumption:** every business below needs ledger (money in/out) + customer tracking. Only differentiators are flagged.

## Legend

**Archetype (the engine it runs on):**
| Code | Engine | Shape |
|---|---|---|
| `SUB` | Subscription | Fixed fee, same people, every month |
| `APPT` | Appointment | Booked slot, mostly single visit |
| `EVENT` | Event booking | Future date, advance + balance |
| `JOB` | Job / Project | Open work, stages, materials |
| `SALE` | Counter sale | Stock in, stock out |

**Needs:** `A` appointment calendar · `R` recurring billing · `S` staff tracking · `I` inventory

**Opportunity:**
| Score | Meaning |
|---|---|
| ★★★ | Build early — high volume, high pain, will pay |
| ★★ | Solid preset — worth shipping in Phase 2 |
| ★ | Long tail — config file only, no dedicated work |

## Where the ★★★ Concentrate

| Archetype | ★★★ count | Read |
|---|---|---|
| `SUB` | ~24 | **Strongest.** Recurring revenue for them = retention for you = they pay for sync |
| `APPT` | ~7 | Solid, but many are single-owner shops with low willingness to pay |
| `EVENT` | ~4 | Small count, high value per user — advance/balance anxiety is real |
| `JOB` | ~6 | High ticket, low volume, sticky |
| `SALE` | ~3 | **Weakest fit.** Khatabook and Vyapar own this; only enter via udhaar |

**The takeaway:** `SUB` is where Khaata wins. Every ★★★ subscription business has the same three problems — who paid, who didn't, who do I chase today. That's Vasooli. You've already built the right screen for the right archetype.

## Build Order Suggestion

1. **`SUB` engine** — unlocks PG, gym, coaching, tiffin, milk, society, school van in one go (already your specced modules)
2. **`APPT` engine** — salon, clinic, garage
3. **`EVENT` engine** — photographer, makeup artist, tent house, catering
4. **`JOB` engine** — contractor, tailoring, mobile repair + all life-event ledgers
5. **`SALE` engine** — last, and only if the udhaar wedge proves out

Five engines. Everything else is a config file: label overrides, default fields, default report.

## Regulatory Note

Excluded deliberately — chit fund, money lending, pawn broking. All regulated in India (RBI / state Money Lenders Acts). A record-keeping app touching these invites scrutiny you don't want as a solo founder.
